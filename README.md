# 数学题库 —— 五年级每日打卡网站

一个纯静态网站，可零成本部署到 **Cloudflare Pages**。白底蓝主题，适配电脑和手机。

> **重要 · 题目来源说明**
>
> - 未能核实学而思《五年级思维向导》的 15 个课程确切名称及 4★/5★ 原题，**没有编造或复制教材原题**。
> - 15 个分类参考公开可查的「学而思五年级目标 S 班（史乐老师）」课程目录整理：[分类参考来源](https://www.fxhaoke.com/shuxue/shuxue05/1347.html)。
> - 题库题目**依据五年级数学知识点编写**，包含原题、讲解、举一反三、配套练习，开箱可用。
> - 你拍照录入的真实原题会保存在本机浏览器，可随时替换。

## 功能

| 功能 | 说明 |
| --- | --- |
| 每日打卡 | 每天自动从题库随机抽 2 题，**当天固定不变**；两题都作答后记录为当天打卡，并统计连续天数 |
| 换一个 | 题目知识点还没学时可换题；换题结果同样当天固定 |
| 我不会 | 点击后直接展示讲解、原题和举一反三，并记为「看过讲解」 |
| 提交判题 | 自动判断对错，随后展示正确答案、讲解、原题、举一反三 |
| **知识点课程** | 30 个知识点各有图文讲解（含公式框、分数条、步骤图等）+ **5 道可自动判分的配套练习**；按 15 分类筛选，记录每课练习进度 |
| **讲解视频** | 暂未录入可确认的视频，仅提供搜索关键词供自行查找（不编造具体视频/UP主）；后续可补充 |
| **错题本** | 所有做错 / 看过讲解的题自动收录；可「再做一遍」，附带两道可自动判分的举一反三练习；**每道错题可展开对应知识点的图文巩固**（纯图文，无视频） |
| **四色状态点** | 没做＝不标；做错＝<span style="color:#ef4444">红点</span>；做对＝<span style="color:#22c55e">绿点</span>；**重做做对 + 两道举一反三全对＝<span style="color:#f59e0b">黄点</span>（完全掌握）**。状态点显示在题库列表、错题本、首页卡片 |
| 按课程分类 | 15 个课程分类，每类 4★ / 5★ 题目 |
| 题库等级 | 当前等级已开放，预留后续等级，可在补充题目页直接录入 |
| 拍照补充 | 上传题目照片（自动压缩）、填写文字/答案/讲解/举一反三，保存在本机 |
| 导入导出 | 补充题目可导出 JSON 备份，也可导入恢复 |

## 部署到 Cloudflare Pages

两种方法任选其一：

### 方法 A：连接 GitHub 仓库（推荐）

1. 把 `mathS` 文件夹推送到你的 GitHub 仓库。
2. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/) → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**。
3. 选择该仓库，配置：
   - **Production branch**：你的主分支（如 `main`）
   - **Build command**：留空（纯静态，无需构建）
   - **Build output directory**：`mathS`（如果仓库根目录就是 mathS 的内容，则填 `/`）
4. 点击 **Save and Deploy**，等待部署完成，得到 `https://xxx.pages.dev` 域名。

### 方法 B：直接上传文件夹

1. Cloudflare Dashboard → **Workers & Pages** → **Create** → **Pages** → **Upload assets**。
2. 项目名填 `mathS`，把整个 `mathS` 文件夹拖进去上传。
3. 部署完成后即可访问。

> 无需数据库、无需后端、零费用。所有学习记录保存在访问者自己的浏览器（localStorage）中。

## 如何拍照补充题目

1. 打开网站 → **补充题目**。
2. 按表单填写：题库等级、课程分类、星级、知识点、**来源说明**（如「《五年级思维向导》P12 第3题（拍照原题）」）。
3. 在「原题图片」处点击选择题目照片（可多选，自动压缩）。
4. 填写正确答案、讲解步骤（每行一步）、易错提示、举一反三。
5. 点 **保存这道题**。题目立即进入对应分类的题库。
6. 想长期备份：点 **导出全部补充题 JSON** 下载文件；换设备时用 **导入 JSON** 恢复。

### 把补充题永久写进网站（可选）

浏览器本地数据只在本机有效。若希望补充的题目对所有人可见，可把导出的 JSON 内容合并进 `js/data.js` 的 `questions` 数组，再重新部署。

## 如何核对 15 个课程分类

编辑 `js/data.js` 中的 `categorySeeds` 数组即可修改分类名称。改完保持对应题目的 `categoryId` 不变，分类会自动更新。

## 如何补充课程与讲解视频

知识点课程数据都在 `js/courses.js` 的 `lessons` 数组里，每个知识点一个对象：

- **改图文讲解**：编辑该课程的 `sections` 数组。每段含 `h`（小标题）、`p`（文字）和 `diagram`（图示）。图示支持 4 种：`formula`（公式框）、`flow`（步骤流程）、`bars`（分数条/线段图）、`note`（提醒框）。
- **改配套练习**：编辑 `practice` 数组（5 道）。每题字段：`q` 题干、`type`（`number` 数字 / `text` 文字）、`ans` 标准答案、`accept` 可接受写法数组、`hint` 提示、`ex` 讲解。
- **补讲解视频**：把该课程的 `video.status` 从 `pending` 改为 `ready`，`video.url` 填你确认过的视频地址（如 B 站视频链接），并填 `title` 标题。页面会自动显示可点击的视频入口。网站不会替你编造或校验视频内容，请自行确认来源。

新增知识点课程时，`kp` 字段必须与 `js/data.js` 里题目的 `knowledgePoint` 完全一致，错题本巩固才能自动对应上。

## 如何新增 L_b / L_c

等级结构已内置，无需改代码：在 **补充题目** 页的「题库等级」选择 `L_b` 或 `L_c` 保存即可。也可以在 `js/data.js` 的 `levels` 数组里调整等级名称和描述。

## 本地预览

```bash
cd mathS
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

> 说明：由于题目图片用 localStorage 存储，直接双击 `index.html` 用 `file://` 打开也能用，但推荐用本地服务器预览以获得完整体验。
